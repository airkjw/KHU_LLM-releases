# KHU_LLM 배포

경희대학교 학생·교직원용 데스크톱 앱 KHU_LLM의 설치 파일을 배포하는 저장소입니다.
소스 코드는 이 저장소에 없습니다.

## 설치

[Releases](https://github.com/airkjw/KHU_LLM-releases/releases/latest)에서 운영체제에 맞는 파일을 받으세요.

| 운영체제 | 파일 |
| --- | --- |
| macOS (Apple Silicon) | `KHU_LLM-<버전>-arm64.dmg` |
| macOS (Intel) | `KHU_LLM-<버전>.dmg` |
| Windows (64비트) | `KHU_LLM-<버전>-x64-Setup.exe` |

설치한 앱은 새 버전이 나오면 이 저장소에서 자동으로 업데이트를 확인합니다.
