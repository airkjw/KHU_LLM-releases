# ChatKHU Desktop

경희대학교 학부·대학원 학생과 교수·교직원을 위한 데스크톱 AI 워크스페이스입니다. 학교 서비스 ChatKHU에서 발급받은 API 키 하나로 대화, 모델 비교, 문서 기반 대화, 이미지·오디오·비디오 생성, 선택한 폴더에서 파일을 읽고, 고치고, 새로 만드는 코딩 작업까지 사용할 수 있습니다. 로그인할 때 고른 신분과 학과에 맞춰 시작 화면과 템플릿, 기본 지침이 준비됩니다.

이 저장소는 설치 파일과 릴리즈 노트를 배포하는 곳입니다. 앱의 소스 코드는 공개하지 않습니다. 저장소 이름은 앱의 이전 이름인 KHU_LLM-releases 그대로입니다.

> **이름 안내**: **ChatKHU**는 API 키를 발급하는 학교 서비스이고, **ChatKHU Desktop**은 그 키로 쓰는 이 앱입니다. 0.5.0까지는 앱을 KHU_LLM이라고 불렀습니다.

## 0.6 주요 변경

> **0.6.0은 macOS에서 실행되지 않는 문제가 있어 내려받기 목록에서 지웠습니다.** 0.6.1에서 고쳤습니다. 0.6.0 이하를 쓰던 경우 아래 [이전 버전에서 넘어올 때](#이전-버전에서-넘어올-때)를 보세요.

- **앱 이름이 ChatKHU Desktop으로 바뀌었고, 설치 파일 이름도 `ChatKHU-Desktop-<버전>-…`으로 바뀌었습니다.** 0.6.1부터는 운영체제 안에서 보이는 이름도 모두 ChatKHU Desktop입니다.
- **이전 화면**: 작업 화면 왼쪽 위의 버튼과 단축키(macOS `⌘[`, 그 밖에는 `Alt+←`)로 직전에 보던 화면과 상태로 돌아갑니다.
- **답변 자리 오류 카드와 다시 시도, 빈 답변 안내**: 답변을 받지 못하면 질문 바로 아래에 이유와 **다시 시도**가 나옵니다.
- **소속 칩과 이 답변은 이렇게 만들어졌어요(맞춤 근거)**: 지금 적용된 소속이 첫 화면에 보이고, 답변마다 소속·지침·모델·웹 검색·사용량을 확인할 수 있습니다.
- **모델 비교 종합분석의 합의·차이 표**: 비교한 답변들의 합의와 차이를 표 하나로 정리합니다.
- **앱 안정성**: 한국어 메뉴(macOS), 두 번 실행해도 창 하나, 화면이 멈췄을 때의 복구 대화 상자, 로그아웃 이유 안내, 손상된 저장 파일 복구(**계정 목록 다시 만들기**).
- **화면 다듬기**: 같은 모양의 빈 화면, 로그인·소속 선택의 단계 표시, 계정 아이콘의 소속 표시, 통일한 용어와 말투.
- **0.6.2**: 왼쪽 아래 프로필 아이콘이 **계정 팝업**(소속·크레딧·업데이트·계정 설정·로그아웃)을 열고, 남은 크레딧이 아이콘 둘레의 **링**으로 늘 보입니다. **모델 비교·챗봇**이 왼쪽 메뉴에 바로 나오고, 새 버전이 준비되면 화면 위 **안내 줄**과 알림이 뜹니다. 코딩에서 **GPT-6 Astra**를 쓸 수 있고, macOS에서 **종료(⌘Q) 한 번으로** 앱이 완전히 끝납니다.
- **0.6.3**: 사용자가 직접 지우지 않은 **코딩 기록을 자동으로 지우지 않습니다**(상한 작업 1,000개·작업 폴더 100개, 가까워지면 정리 안내). 소속을 고를 때 **저장 전에 시작 화면을 미리** 볼 수 있고, 이미지·미디어 생성 중에는 로그아웃·키 교체를 막아 결과를 지킵니다. **0.6.3을 쓴 뒤 0.6.2 이하로 되돌려 설치하지 마세요.**
- **0.6.4**: 대화 입력창에서 시작한 **모델 비교가 그 대화에 저장**됩니다. 새 대화에서 첫 질문을 비교로 보내도 대화가 목록에 오르고 **+(새 대화)**가 동작하며, 다시 열어도 비교가 보입니다. **코딩 화면에도 PDF·HTML 등 문서**(PDF·DOCX·XLSX·PPTX·HWPX·HTML·TXT·MD·CSV)를 붙일 수 있습니다.
- **0.6.5**: Windows에서 저장하는 순간 같은 파일을 읽고 있으면 저장이 실패할 수 있던 문제를 고쳤습니다(짧게 다시 시도). 로그아웃할 때 지운 API 키가 다시 살아나지 않게 저장 순서도 다듬었습니다.
- **0.6.6**: 프로젝트 문서가 40,000자 안이면 **빠짐없이 전부** 전달되고(이름이 같은 문서도 따로), 넘치면 어느 부분을 뺐는지 함께 알려 줍니다. 새 대화 첫 저장 실패 처리, 이어서 생성 규칙(마지막 답변에서만), 미디어 저장 오류 처리를 다듬었고, 코딩 예시를 만들 결과 중심 문장으로 바꿨습니다.

자세한 내용은 [릴리즈 노트](https://github.com/airkjw/KHU_LLM-releases/releases/latest)를 보세요.

## 주요 기능

- 신분(학부생·대학원생·교수·교직원)과 소속(캠퍼스 → 단과대학·대학원 → 학과·전공)에 맞춘 첫 화면, 시작 템플릿, 기본 지침
- 지금 적용된 소속을 보여 주는 소속 칩과, 답변마다 어떤 설정으로 만들어졌는지 보여 주는 **이 답변은 이렇게 만들어졌어요**(맞춤 근거)
- ChatKHU가 현재 계정에 허용한 채팅·미디어 모델 선택, 최대 3개 모델 답변 비교와 합의·차이 표로 정리하는 종합분석
- Gemini·Sonar의 직접 웹 검색과 그 밖의 모델을 위한 Sonar 검색 연동
- 이미지 생성, 음성 합성·받아쓰기·음악, 비디오 생성, 받아쓰기 결과의 회의록 요약
- PDF·DOCX·XLSX·PPTX·HWPX·TXT·MD·CSV·이미지 첨부와 문서 내용 기반 대화
- 연구별 지침과 문서를 묶는 프로젝트, 논문·법령 리서치, ChatKHU Studio 챗봇
- 코딩 작업 공간: 채팅하듯 요청하면 모델이 선택한 폴더의 파일을 읽고 고치거나 새로 만드는 변경을 제안합니다(빈 폴더에서도 시작 가능). 파일마다 변경 내용을 확인해 적용하고 체크포인트로 되돌립니다. 권한 모드(묻기·편집 자동·계획·전체 자동)로 확인 방식을, 모델 옆에서 사고 강도(자동·낮음·중간·높음 등, 모델에 따라 다름)를 고르고, 셸 명령은 설정에서 직접 켜야 하며 승인한 것만 실행됩니다. 전체 자동은 설정에서 경고를 확인해야 켜지고, 파일 수정·명령·git(올리기 포함)을 묻지 않고 진행하며 비용은 알림 기준(80%·100%)에서 알리기만 하고 멈추지 않습니다(macOS는 샌드박스 — 명령을 작업 폴더 안에 가두는 격리 장치 — 안에서 실행하고, Windows는 샌드박스 없이 내 계정 권한으로 실행합니다). 개발 서버를 띄워 앱 안 미리보기로 확인하고, 웹 검색·여러 파일 읽기·맥락 압축을 쓸 수 있습니다. 이미지 입력이 확인된 모델(Claude 5·GPT-5 계열)에서는 이미지를 붙이거나 끌어다 놓을 수 있습니다. git 저장소 만들기·복제, 브랜치, 커밋, 받아 오기·합치기·올리기·병합은 전체 자동이 아니면 항상 승인하며 강제로 덮어쓰는 올리기는 없습니다.
- 경희대 크레딧이 모두 소진되면 내 OpenAI·Claude·Gemini 개인 키(예비 키)로 이어서 대화·코딩을 할 수 있습니다. 선택 기능이며, 회사마다 처음 한 번 동의를 받고, 요금은 내 계약으로 청구되며, 키는 이 기기에만 암호화해 저장합니다.
- 작업 화면의 **이전 화면** 버튼, 답변을 받지 못했을 때의 오류 카드와 **다시 시도**, 화면이 멈췄을 때의 복구와 손상된 저장 파일 복구
- 운영체제 보안 저장소를 이용한 API 키 보호, 기기 안에 암호화해 보관하는 대화 기록, 암호로 보호하는 백업·복원
- macOS(한국어 메뉴 포함) Intel·Apple Silicon 및 Windows 지원

## 설치

[최신 버전 내려받기](https://github.com/airkjw/KHU_LLM-releases/releases/latest)에서 아래 파일 중 사용하는 컴퓨터에 맞는 것을 받아 설치합니다.

| 운영체제 | 파일 |
| --- | --- |
| macOS Apple Silicon | `ChatKHU-Desktop-<버전>-arm64.dmg` |
| macOS Intel | `ChatKHU-Desktop-<버전>-x64.dmg` |
| Windows x64 | `ChatKHU-Desktop-<버전>-x64-Setup.exe` |

- `.zip`·`.blockmap`·`.yml` 파일은 자동 업데이트용이라 받을 필요가 없습니다.
- 0.5.0까지의 설치 파일 이름은 `KHU_LLM-<버전>-…`이었고, 0.6.0부터 위의 이름입니다.
- macOS 앱은 Developer ID 서명과 Apple 공증을 거칩니다.
- 0.6.1부터 앱 이름이 어디서나 ChatKHU Desktop입니다. macOS는 응용 프로그램 폴더·Dock·메뉴 막대·활성 상태 보기에서, Windows는 설치 폴더·시작 메뉴·바탕 화면 바로 가기·작업 관리자에서 같은 이름이 보입니다.

### Windows에서 설치할 때

Windows 설치 파일에는 별도의 코드 서명(Authenticode)이 적용되어 있지 않아, 설치 파일을 처음 실행하면 Windows SmartScreen이 **Windows의 PC 보호** 화면으로 실행을 막을 수 있습니다. 이때는 다음 순서로 설치를 이어 가세요.

1. 화면의 **추가 정보**를 누릅니다.
2. 새로 나타나는 **실행** 버튼을 누릅니다.

이 저장소의 릴리즈에서 받은 파일일 때만 실행하세요. 다른 곳에서 받은 파일은 실행하지 마세요.

### 이전 버전에서 넘어올 때

**0.6.0 이하를 쓰고 있다면 0.6.1 이상의 설치 파일로 새로 설치해 주세요.** macOS의 0.6.0은 실행되지 않아 자동 업데이트를 받을 수 없습니다. 이전 버전의 대화·설정·로그인 정보가 새 앱으로 이어지는 것은 보장하지 않습니다. 처음 실행하면 API 키로 다시 로그인해 주세요.

이전 앱(**KHU_LLM**)이 남아 있으면 지워 주세요. macOS는 응용 프로그램 폴더의 KHU_LLM을 휴지통으로 옮기고, Windows는 설정 → 앱에서 KHU_LLM을 제거합니다.

## ChatKHU API 키 발급 방법

1. [ChatKHU 로그인 페이지](https://chat.khu.ac.kr/auth)에 접속해 Info21 아이디와 비밀번호로 로그인합니다.

2. 로그인 후 왼쪽 아래의 **API Gateway**를 클릭합니다.

   <img src="images/api-key-step-2.png" alt="ChatKHU 왼쪽 아래의 API Gateway 메뉴" width="900">

3. API 키 관리 화면에서 **+ API 키 생성**을 누릅니다.

   <img src="images/api-key-step-3.png" alt="API Gateway의 API 키 생성 버튼" width="900">

4. API 이름을 입력하고 **생성하기**를 누릅니다. 설명은 필요할 때 입력하면 됩니다.

   <img src="images/api-key-step-4.png" alt="API 키 이름을 입력하고 생성하기를 누르는 화면" width="600">

5. API 키가 생성되면 **복사**를 눌러 메모장 등 안전한 곳에 보관합니다. 이 키는 한 번만 표시되며, 잃어버리면 새로 만들어야 합니다. 복사한 API 키가 ChatKHU Desktop의 로그인 키가 됩니다.

   <img src="images/api-key-step-5.png" alt="생성된 API 키를 복사하는 화면" width="450">

## 개인정보 안내

- **API 키**: 앱에 입력한 API 키는 이 기기의 운영체제 보안 저장소로 보호됩니다.
- **첨부 자료**: 앱을 켠 뒤 처음 자료를 보낼 때(대화 첨부, 프로젝트 문서 추가, 미디어 생성, 모델 비교) "개인정보·민감정보를 제거한 자료만 보냅니다" 확인 창이 한 번 나타나고, 그 실행 동안에는 같은 계정에서 다시 묻지 않습니다. 앱을 다시 켜거나 다른 계정으로 로그인하면 다시 묻습니다. 앱이 개인정보를 자동으로 탐지하거나 제거하지 않으므로 전송 전에 직접 제거해야 합니다.
- **미디어 생성**: 첨부 자료가 없어도 위 확인을 거쳐야 시작할 수 있습니다.
- **선택한 신분·소속**: 기본 지침에 포함되어 ChatKHU API로 전송됩니다(설정의 "답변에 소속 반영"을 끄면 신분·학과 이름은 포함되지 않습니다. 학과별 어투·주의 문구는 남아 전공 분야를 짐작할 수 있습니다). 학번·이름·이메일은 입력받지 않으며, 신분과 소속만 이 기기에 암호화해 보관합니다.
- **질문과 음성**: 입력한 질문과 음성 기능의 마이크 음성은 ChatKHU API를 거쳐 선택한 모델 제공사로 전송됩니다. 원본 음성은 저장하지 않습니다. 음성 대화의 확정 텍스트는 세션이 끝난 뒤 "텍스트 저장"을 누르고 확인 창에서 동의할 때만 이 대화에 암호화 저장됩니다.
- **예비 개인 키**: 경희대 크레딧이 소진되어 개인 키로 전환하거나 직접 바꾸면, 대화·코딩 내용이 ChatKHU API가 아니라 선택한 회사(OpenAI·Anthropic·Google)로 직접 전송되고 요금은 내 계약으로 청구됩니다. 회사마다 처음 한 번 동의를 받습니다. 키는 이 기기의 운영체제 보안 저장소를 쓰는 암호화 파일로만 보관하며 백업에 포함되지 않고, 로그아웃하거나 다른 API 키로 로그인하면 삭제되고 앱을 켤 때 경희대 API 키가 거부되어도 함께 삭제됩니다. 웹 검색·리서치·챗봇·미디어·음성·문서 의미 검색·모델 비교는 개인 키로 쓸 수 없고 경희대 크레딧으로만 동작합니다. 모델 자체 웹 검색 도구는 개인 키로 처음 보낼 때 켤지 한 번 묻습니다. 보낸 내용의 보관·학습 여부는 그 회사 정책을 따르며 앱이 보증하지 못합니다(Gemini 무료 등급 키는 Google 서비스 개선에 쓰일 수 있습니다).
- **코딩**: 요청, 작업 폴더 맨 위와 모델이 열어 본 폴더의 파일·폴더 이름 목록, 모델이 읽거나 검색한 파일 내용, 승인한 명령의 출력(셸 출력은 비밀 값 패턴으로 보이는 줄을 가린 뒤), git 상태·변경 내용·커밋 기록(커밋 메시지와 작성자 이름), 명령이나 git 도구의 출력에 나오는 git 원격 주소, 모델이 읽은 서버 로그, 미리보기 화면 캡처와 콘솔 메시지(로그·콘솔은 비밀 값 패턴으로 보이는 줄을 가린 뒤, 화면 캡처는 묻기·계획 모드에서 승인한 뒤), 웹 검색어(검색 모델로), 첨부한 이미지(축소본), 이 컴퓨터의 개발 도구 버전(Node·npm·Python·git·셸)이 ChatKHU API를 거쳐(예비 개인 키로 전환한 뒤에는 해당 회사로 직접) 선택한 모델 서버로 전송되고, 모델 호출마다 크레딧이(개인 키 경로에서는 내 계약의 요금이) 사용됩니다. 화면 캡처와 이미지 첨부는 이미지 입력이 확인된 모델(Claude 5·GPT-5 계열)을 고른 작업에서만 전송됩니다. 편집 자동·전체 자동에서는 모델이 쓴 웹 검색어가 카드 없이 전송됩니다. 개인정보·민감정보가 든 파일은 작업 폴더에 두지 말고, 파일 이름에도 개인정보를 넣지 마세요. `.env`·키·인증서 파일처럼 비밀 값이 들어 있을 수 있는 파일은 기본으로 보내지 않고, 허용하면 그 작업에서 그 파일 하나만 보냅니다. 이 판정과 명령 출력·로그의 비밀 값 가림은 보조 장치입니다. 전체 자동에서도 모델로 전송되는 내용은 위와 같고, 샌드박스 점검 보고서는 외부로 전송되지 않습니다. 명령·셸 실행은 설정에서 직접 켜야 하고, 승인한 명령은 내 계정 권한으로 실행됩니다. git 저장소 만들기·복제, 브랜치 만들기·전환, 커밋, 받아 오기·합치기·올리기·병합은 전체 자동이 아니면 항상 승인하고, 전체 자동은 묻지 않고 실행합니다(전체 자동의 앱 도구는 비밀 파일도 묻지 않고 읽어 모델에 보냅니다). 올리기는 내가 승인한 원격 저장소 서버로 커밋을 보내는 것이라 모델로 보내는 것과 별개이며, 승인 카드는 커밋 제목만 보여 주므로 올라가는 커밋에 비밀 값이 없는지는 직접 확인해야 합니다. 미리보기는 이 컴퓨터의 localhost 허용 포트만 열고, 외부 리소스 허용을 켠 폴더에서만 외부 서버와 통신합니다. 코딩 작업 기록(저장된 명령 출력·웹 검색어 포함)·붙인 이미지·체크포인트·허용한 명령은 이 컴퓨터에만 암호화해 저장합니다.
- **진단 정보와 오류 기록**: **진단 정보 복사**와 설정 → 진단에는 버전·운영체제·단계·모델 이름과 최근 오류 최대 3줄이 담깁니다. 오류 문장에 섞인 API 키, 이메일, 사용자 폴더 경로, 첨부 파일 이름은 가립니다. 이 가림은 보조 장치입니다. 오류 기록은 이 기기에만 남고 외부로 전송되지 않습니다.
- **기기 안의 기록**: 대화 기록과 코딩 작업 기록(저장된 명령 출력·웹 검색어 포함), 붙인 이미지, 예비 키는 이 기기에 암호화해 보관합니다. 백업 파일에는 API 키와 예비 키가 들어가지 않습니다.

## 자동 업데이트

앱은 이 저장소의 릴리즈에서 새 버전을 확인하고 업데이트합니다. 0.6.2부터는 새 버전이 준비되면 화면 위 안내 줄의 **지금 재시작**으로 바로 설치하거나, **나중에**를 눌러 앱을 끌 때 설치되게 할 수 있습니다. 0.6.0 이하에서는 자동 업데이트 대신 위의 [이전 버전에서 넘어올 때](#이전-버전에서-넘어올-때)대로 새로 설치해 주세요. 앱이 알아서 하는 업데이트 확인이 실패해도 더는 오류 표시가 뜨지 않습니다. 0.1.0 앱에서는 업데이트 확인 오류 표시가 보일 수 있는데, 다시 시도하지 말고 새로 설치하면 됩니다.
